個人用Google Driveバックアップ認証アプリ / Personal backup authorization app

目的 / Purpose

このアプリは、所有者の研究プロジェクトに関するファイルを、本人のGoogle Driveに保存し、復元・整合性確認するための個人用バックアップ認証アプリです。rcloneと組み合わせて利用します。

This private-use OAuth application authorizes rclone to back up and restore the owner's research project files in the owner's own Google Drive.

Google Driveの権限 / Drive permissions

要求する権限は https://www.googleapis.com/auth/drive.file です。アプリが作成したファイル、または所有者が明示的に許可したファイルのみを扱います。Drive全体への包括的なアクセスは要求しません。

Only the drive.file scope is requested; unrelated personal Drive files are not in scope.
